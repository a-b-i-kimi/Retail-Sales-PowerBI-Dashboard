# Retail Sales Performance Dashboard (Power BI)

This project presents an interactive retail analytics dashboard built using Power BI.

## Objectives

* Analyze overall business performance
* Track revenue, profit, orders and customers
* Identify top performing regions
* Understand category-wise sales contribution
* Visualize monthly sales trends

## Features

* KPI Cards for business metrics
* Monthly revenue trend analysis
* Regional performance comparison
* Category contribution visualization

## Tools Used

* Power BI
* Data Cleaning & Transformation
* Data Visualization
